## Context

現有 protocol/metrology/model.go 直接產生 49 個膜厚點及缺陷座標，MetrologyPanel.vue 呈現兩類圖。KLA 完成資料已經過 SECS/GEM、Sparkplug B、Kafka 持久化。本設計為下游分析，不修改其完成契約；動機見 proposal.md。此變更跨服務與資料庫，需獨立設計。

## Goals / Non-Goals

**Goals:** 可追溯的公開資料重播與模擬影像檢查，兩種分析各自可失敗及重試；原圖、參數、輸出可重現。

**Non-Goals:** 真實 KLA 驅動、相機接入、真實 TiN 缺陷成因診斷、以照片推算膜厚、自動報廢／停機／簽核／Email、深度學習訓練平台。公開影像與目前製程的關聯是展示關聯，不代表同一實體晶圓。

## Decisions

### 資料優先順序與來源

先查核 Kaggle 資料頁及下載樣本，再決定可用子集。候選：
- WM-811K：https://www.kaggle.com/datasets/qingyi/wm811k-wafer-map ，資料頁標示 CC0、811,457 張 wafer map；屬 die 狀態網格，不是表面照片。
- Mixed-type：https://www.kaggle.com/datasets/co1d7era/mixedtype-wafer-defect-datasets ，約 38,000 張混合分布圖，需另查授權、標註及來源。
- ISSM SEM：https://www.kaggle.com/c/issm-AI-tech-contest-2020/data ，頁面要求邀請及競賽條款，不預設可取得或可公開展示。

實作查核已選用同源小型 Kaggle 子集 muhammedjunayed/wm811k-silicon-wafer-map-dataset-image v1（CC BY-SA 4.0），902 張中取九類各 20 張，詳見 docs/cvd/vision/datasets.json。該子集為 32×32 渲染 JPG，缺少原始 die 網格；因此分析的是渲染像素區域，不宣稱壞 die 數。表面資料仍以模擬補齊。以清單保存 datasetId、版本、來源 URL、授權證據、樣本 ID、雜湊、類別、標註種類、比例尺及適用模態。無可用授權／存取或缺少適合標註的類別記錄缺口，以固定 seed 的合成影像補齊；不得用其他材質照片冒充晶圓。先取有界代表子集，避免直接下載所有 2.1 GB 資料。

資料集重播與模擬生成明確分開。模擬答案、資料集類別標籤不傳入推論輸入，只供獨立評估。PKL 等可執行反序列化格式只在無憑證、無網路、有限資源隔離匯入環境轉換為安全陣列／圖片，執行服務不載入 pickle。保留官方來源及雜湊。

### 分析服務與資料流

採 Python OpenCV 無 GUI Docker 工作服務，方便影像處理及離線評估；相較嵌入 Java 原生函式庫或 GoCV，隔離原生依賴及影像解碼負載。Go 繼續負責設備與閘道器。

KLA completed 持久化後，Java 交易建立唯一 measurementId 的檢查組及 map/surface 兩個工作與 outbox。Kafka 傳工作參照及結果，圖片不塞進 SECS、每秒 telemetry、Redis 或 Kafka。工作服務從內部授權介面讀取受控圖片、寫入結果；這是 Data Platform 下游，不增加假的設備協定回傳。

分布分析以原始 die 網格、圓片遮罩、連通區與徑向／角向分布等特徵建立版本化規則基線；支援中心、環狀、邊緣、局部、隨機、刮傷、近全片及混合候選，難以區分時回傳 uncertain，不硬猜。表面分析以背景校正、分割及形狀特徵產生顆粒、線狀刮傷、斑點候選。首版不承諾未驗證的準確率或把規則分數稱為機率。

### 結果與單位

檢查保存 inspectionId、measurementId、來源 CVD/PM/wafer/processRunId、檢查版本、來源模式、資料集樣本或 seed、輸入雜湊、演算法／OpenCV 版本、參數快照及判定原因。重分析建立新版本且沿用凍結輸入；重新選樣須形成新來源紀錄。既有 KLA 缺陷與 OpenCV 結果分開展示，不能覆蓋。

map 保存 die 座標與方向；表面保存影像像素座標、輪廓／框與面積。僅有有效比例尺才顯示物理尺寸；只有局部 SEM 照片不能推定全片位置，無註冊轉換時不疊到全片 map。模擬全片影像可用已保存轉換連動全片座標。膜厚仍沿用既有量測。

### 可靠性、權限與保存

工作狀態 queued/running/completed/failed，兩種獨立狀態；failed、uncertain、未執行與零缺陷不同。完成後每個檢查版本最多一則品質告警，列出兩種已完成分析的異常原因；兩工作皆終止才彙整，失敗者清楚標示，不把技術錯誤當品質合格。有限次技術重試沿用原工作 ID，租約到期可恢復；結果唯一鍵去重，持久化後才 ACK。

Operator 可讀，Engineer/Leader 可重分析，沿用登入、設備授權、CSRF 及冪等鍵。首版無網頁上傳及調參功能。原圖及衍生圖置持久 volume，PostgreSQL 保存參照及結果，透過後端授權提供，不公開任意檔案路徑。原子發布前驗證圖片與結果存在，限制解碼像素、檔案大小、工作超時及佇列；不得靜默丟片。

保留最近 30 天，進行中工作與未結案告警引用不提前刪除；刪除採引用檢查，過期清楚標示。共用來源樣本去重，不因十台設備重播而反覆存圖。部署前以代表樣本估算磁碟及十台量測吞吐，資源上限配置化。

### 畫面與評估

晶圓 KLA 詳情增加視覺檢查區，分布／表面 Tab，原圖／標記圖切換、缺陷列表、來源、版本、未知／失敗／過期提示；支援三語、手機與鍵盤。Kaggle 重播始終顯示展示用途，不冒充當片實測。

離線依原始 wafer/lot 或來源影像分組切分資料，同圖衍生版本不得跨評估分組。分類報告逐類 precision/recall/F1 與混淆；有框／mask 才計算定位或分割指標，未標註資料不計準確率。真實公開資料與合成資料分開報告。首版驗收確保管線真實執行、失敗可見、輸出合法與可重現；辨識效能如實公布，不設臆測準確率。

## Risks / Trade-offs

- [公開資料不足或條款限制] → 保存缺口證據，按已授權策略用模擬資料補齊。
- [分布圖被誤認為顯微照片] → 模態、座標與來源分列，不互換物理尺寸。
- [規則基線泛化有限] → uncertain 狀態與逐類評估，不自動品質放行。
- [影像增加磁碟／CPU] → 有界子集、去重、30 天引用安全清理及獨立資源限制。

## Migration Plan

1. 備份資料與配置，新增表、topic 與 volume，預設關閉。
2. 查核樣本與授權，完成離線分析、獨立評估及隔離環境端到端驗收。
3. 啟用時記錄界線，只對啟用後完成的 KLA 量測送檢，不補造舊晶圓結果。
4. 驗證十台設備、KLA、RBAC、告警與三語手機 UI，不啟動或變更正式批次造測試資料。
5. 回退停新派送、保留工作與圖片，再回退 UI／服務；重新啟用可續作，不刪 volume。
