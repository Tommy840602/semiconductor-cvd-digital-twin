## Context

參見 proposal.md。現有 Vue 3 App 以 fleet 卡片進入單台 EquipmentTopology，已有設備摘要與選台流程。GLB 來源為 TEL_Triase_V25_4_PM1_blue_block_attached_left_face.glb，224116 bytes、246 meshes、247 nodes，未包含動畫。節點名稱不能直接當成現有 PM1～4 的語義映射。

本變更新增 Three.js 與場景生命週期管理，具有新依賴及效能複雜度，因此需要本設計文件。

## Goals / Non-Goals

**Goals:** 空間總覽與現有設備資料分離；模型共用但設備身分及狀態独立；人物控制在桌面與手機一致。

**Non-Goals:** 單機內部 3D、晶圓搬送動畫重製、真實人員定位、多人連線角色、人物軌跡入庫、CFD／潔淨度物理模擬及後端製程修改。

## Decisions

### 場景與資料接點

Vue 封裝 Three.js 場景，從 App 傳入既有 fleet 摘要，選台事件呼叫既有 selectEquipment 流程。相較導入完整遊戲引擎，直接整合既有 Vue 狀態與 UI 成本較低。使用摘要刷新節奏，畫面插值與人員動畫獨立於設備每秒採樣；不為十台各開詳情訂閱。WebSocket／摘要服務既有品質旗標為離線或陳舊判斷依據。

### 模型與配置

實作時將來源模型納入前端靜態資源並記錄來源與 checksum；本規劃不複製資產。載入一次並共享 geometry，狀態標記獨立，必要時材質複製以避免跨台變色。以根物件綁定完整 equipmentId，不依 mesh 名稱判斷機台。

採 Y 向上、地面 XZ，走道長向 Z；01～05 在一側、06～10 在另一側，成對相對且 LP 朝中央。以配置資料記錄每台位置與朝向。先量測模型包圍盒及辨識正面，再按模型尺寸保留走道與設備間隙。實際尺寸未獲提供，首版明示為示意配置，不宣稱測繪精度。固定一套共用比例，禁止各台任意縮放。

### 人物與移動

首版採一名可操控的無塵衣人物，使用自動巡走／手動操控單一狀態機；這是實作預設，避免推定多人同步需求。人物資產需可合法隨網站配送並具有站立／走路動畫；必要時製作簡化人物。

固定走道使用路徑點與設備前停留點，採平面可行走區域、設備膨脹碰撞盒和角色半徑限制；相較完整導航網格，符合固定單走道需求。每幀依經限幅的 delta time 更新，防止掉幀穿越障礙；若有其他人物，同樣需避讓。自動轉手動立即停止路徑驅動，保留位置；轉回自動從可達路徑接續，無有效路徑則停留提示，不瞬移。

WASD／方向鍵與虛擬搖桿統一為移動向量，斜向速度正規化；文字輸入、失焦、切頁、pointercancel 時清除輸入。巡走純前端展示，不產生設備操作指令。

### 相機與互動

手動模式預設第三人稱跟隨；全場俯視可返回，俯視期間停止手動位移並保留人物位置，回到跟隨再接收移動輸入。相機避免穿入設備。自動巡走可從俯視或跟隨觀察。設備點擊與拖曳／搖桿事件分離；設備摘要提供桌面 hover 和手機點選，進入詳情使用明確操作。返回總覽保留本次頁面內人物位置及模式，不要求跨重整保存。

### 韌性與效能

載入中提供進度／等待提示；模型失敗、WebGL 不可用或 context lost 時提供可操作的既有設備清單與重試。模型內容不影響後端權限；所有實際操作仍走現有 API 授權。

頁面隱藏或離開總覽停止動畫更新，返回後從當前位置續行，避免補算背景經過時間。場景卸載釋放 renderer、資源、事件監聽及動畫迴圈。共用資源統一釋放，避免單台釋放波及其他台。限制手機 pixel ratio 與陰影、合併可合併的靜態物件；246 meshes 複製十次的 draw calls 必須實測，檔案小不代表渲染快。

## Risks / Trade-offs

- 模型比例、朝向或色彩不符 → 視覺檢查並記錄正規化設定，保留原始資產。
- 手機 GPU 負荷與過熱 → 低畫質模式、減少陰影與 draw calls；測量明確裝置／瀏覽器，目標穩態至少 30 FPS，未達時先優化再宣稱支援。
- 點錯設備或共享材質串台 → 完整 ID 標記與兩台不同狀態測試。
- 模型缺少人物動畫 → 人物獨立資產，不以機台 GLB 內建動作為前提。

## Migration Plan

1. 在開發／驗證環境加入場景及靜態資源，不改資料庫與生產加工狀態。
2. 驗證十台 ID、狀態、詳情跳轉、角色控制、行動裝置與降級路徑。
3. 建置前端映像，部署時保留原映像作回退；不重新初始化批次、recipe、帳號或簽核。
4. 異常時回退前端映像，不涉及業務資料還原。

## Open Questions

- 實際走道與機台間距尚未提供；先用包圍盒導出的示意尺寸，後續可只調配置。
- 人物美術樣式與可配送素材待實作選定，不影響已定控制契約。
