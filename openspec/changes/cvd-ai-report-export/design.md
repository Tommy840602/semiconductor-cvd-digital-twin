## Context

現有 Java 21 Spring 後端提供 StatisticsApi、UtilizationApi、MetrologyApi、VisionApi 與 VacuumApi，資料來自 PostgreSQL／TimescaleDB；前端 Vue 3 已支援三語與日夜主題。尚無報告工作或 OpenAI 整合。動機見 proposal.md。

## Goals / Non-Goals

**Goals:** 固定同一報告資料版本，讓預覽、AI 摘要與 Excel 可相互核對；背景生成不阻塞即時製程。

**Non-Goals:** 不提供 AI 設備控制、簽核、自動報廢或診斷定論；不包含 Cp／Cpk、定時寄送或 PDF。第一版不把全量影像與秒級原始資料送到 LLM。

## Decisions

### 資料快照與範圍

沿用今日、最近 24 小時、7 天、30 天，單台或全部十台，固定 Asia/Taipei 的 [start,end)。新增報告資料適配層重用既有查詢規則，支援共同截止時間，不透過模擬現在狀態重建歷史。工作建立時固定參數，收集完成後保存不可變資料快照與雜湊；後續晚到資料只有新報告才採用。跨 PostgreSQL／TimescaleDB 的擷取並非單一資料庫交易，記錄各來源擷取時間與版本，禁止宣稱全域原子快照。

KLA 依量測完成時間落入區間並選截至截止時最新有效版本；OpenCV 依檢查完成時間選最新有效版本，保留影像來源／合成標記、規則版本與待複核結果。這些區間與正式晶圓結案計數不同，報告明示各自分母，不推導為正式良率。PHM 趨勢按歷史抽氣事件的健康觀測彙整，標示事件取樣而非每秒完整趨勢；區間末端值另取截止前最近一筆歷史 telemetry。避免每份報告掃描大型秒級 JSON，保持即時製程可用。無歷史剩餘次數時標示無資料，不能填入現在值冒充區間資料。缺口、未知、未量測、待確認與 Dummy 各自呈現。

### LLM 的責任與驗證

後端呼叫 OpenAI Responses API，以 JSON Schema 定義章節、來源指標引用、圖表類型與資料集引用。圖表限定甘特、圓環、長條、趨勢等允許類型，不接受生成程式碼。確定性程式計算指標、格式化數字、產生圖表，LLM 只組織敘述與選擇既有資料集。拒絕不存在的引用、擅自新增數值、超出期間比較與無證據根因；摘要標示「AI 分析」及人工判讀提醒。結構化格式不保證語意正確，另設資料引用驗證與測試。

只送必要彙整及不含帳號／郵件／密碼／金鑰的內容；資料送往外部 OpenAI 服務於頁面說明。API 金鑰只由後端 Docker secret／環境設定提供，模型以設定指定，不綁死未驗證版本。不使用網站 ChatGPT 登入憑證。沒有金鑰時顯示尚未設定，不能偽造 AI 摘要。

### 背景工作與權限

新增 POST /api/reports、GET /api/reports、GET /api/reports/{id} 與 GET /api/reports/{id}/download。已登入 Operator／Engineer／Leader 皆可生成，第一版僅可查閱下載自己建立的報告；全程不產生控制或簽核命令。PostgreSQL 保存工作狀態、建立者、範圍、語言、快照雜湊、模型／提示版本、錯誤與檔案資訊，持久化工作佇列配合後端有限 executor，不增加獨立服務。

狀態 queued、collecting、analyzing、rendering、completed、failed；階段進度不宣稱精確百分比。預設全系統最多 2 個執行中工作、每人 1 個未完成工作；相同冪等鍵不重複呼叫。API 暫時錯誤有限重試最多 2 次，重啟對未完成工作標示中斷，由使用者重試，避免無上限花費。前端僅報告頁面可見時低頻輪詢，離頁停止。

### Excel 與圖表

Java 使用 Apache POI SXSSF（XSSF 串流寫入） 產生工作簿，程式由同一快照繪圖並嵌入圖片。相較全數依賴 Excel 原生圖表，此方式能穩定呈現甘特圖；分頁數值仍可供使用者自行分析。第一版不承諾嵌入圖表可直接編輯。

分頁：報告摘要、設備統計、狀態時間軸、KLA 量測、視覺缺陷、真空 PHM、資料品質、報告資訊。包含 AI 總結、圖表、型別正確的數值、單位、來源版本、區間與擷取時間。外部文字強制寫成字串，不執行公式或外部連結。預覽與下載使用同一已完成產物。支援三語及日夜預覽，Excel 使用明亮列印配色。

預設保存 30 天，檔案置於 Docker 持久化 volume，以不含使用者路徑的 UUID 定位；最多 50 MB／報告及 100,000 明細列，超限明確失敗，不能靜默截斷。清理不影響原始來源保留策略。

## Risks / Trade-offs

- AI 敘述誤判 → 指標引用驗證、明示未知、無證據不寫根因，保留快照方便核對。
- 外部 API 延遲與費用 → 有限併發／重試、只傳彙整、記錄用量，不在即時輪詢自動生成。
- 大報告耗費記憶體 → 有限查詢與明細上限、分批讀取與生成，驗證 30 天十台負載。
- 圖表圖片無法直接編輯 → 提供各圖表來源數值與解析度，後續再評估原生圖表。
- 模擬資料被當真實診斷 → 每份報告標示模擬設備、合成影像與 PHM 模型限制。

## Migration Plan

新增報告資料表與檔案 volume，不改既有資料或模擬器；先以隔離 API stub 測試，再用設定好的 OpenAI API 進行小範圍驗證，最後開啟入口。未設定 API 時入口仍能說明設定不足。回滾後端／前端版本可停用入口，保留新增資料表與報告檔案，不刪除既有業務資料。
