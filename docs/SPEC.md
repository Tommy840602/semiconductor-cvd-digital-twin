# 工業監控儀表板規格 v1

## 範圍
供值班人員監看產線設備、即時趨勢及告警。v1 使用明確標示的模擬資料，每 2 秒更新；不連接真實 PLC、不下發控制命令。介面使用繁體中文。

## 需求與驗收
- R01：總覽顯示設備數、運轉數、未確認告警數與平均溫度；數字由目前產線篩選下的同一份資料計算。
- R02：可切換全部／A／B 產線。設備、摘要與告警同步篩選；選取設備若不在新範圍，改選首台。
- R03：點選設備更新趨勢與溫度、壓力、振動讀值。提供溫度／壓力／振動切換與最近 1／5 分鐘視窗；趨勢標明單位及時間。
- R04：每 2 秒新增樣本，最多保留 150 點；暫停模擬時停止新增，再次啟動後恢復。停機設備保留狀態、不生成運转讀值。
- R05：溫度超過 85°C 產生警告，超過 95°C 產生嚴重告警。持續超限不可重複新增同設備同事件；恢復正常後再次超限可新增。
- R06：告警顯示設備、時間、等級、訊息與確認狀態。確認僅改變本次瀏覽工作階段的告警紀錄，不清除超限狀態；可篩選未確認或全部。
- R07：無符合告警時顯示空狀態。桌面與行動裝置皆可操作，使用原生可鍵盤操作控制元件與明確焦點。

## 資料契約
Device: id, name, line, running, samples[{time, temperature, pressure, vibration}].
Alarm: id, deviceId, time, severity, message, acknowledged.
即時資料來源目前為瀏覽器模擬器；後續真實串接須另行定義協定、認證、斷線/過期資料處理與後端告警持久化。

## 驗證
使用 Node 測試核心資料邏輯：產線篩選、告警閾值/去重/恢復後重觸發、確認與活動狀態分離、樣本容量。語法與靜態資產引用檢查。未執行真實設備整合測試。
