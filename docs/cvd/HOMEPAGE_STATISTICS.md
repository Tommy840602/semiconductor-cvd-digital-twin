# 首頁統計圖表

首頁分為「3D 無塵室、稼動率、狀態時間軸、狀態占比、晶圓產出」五個分頁，預設顯示 3D，一次只顯示一個區塊。統計分頁共用今日、24 小時、7 天、30 天篩選，切換分頁保留區間與選台，截止時間與既有機台稼動率／PM 使用率一致。今日從台灣午夜起算，每 30 秒更新。自動更新保留圓環圖選台，切換區間會清除上一區間資料；查詢失敗可重試。

- **機台狀態時間軸**：10 列完整設備編碼。滑鼠、鍵盤聚焦／Enter 或點選色帶查看時間、持續時間及 PM 故障、派片暫停、保養階段等旗標。手機可在圖內橫向捲動。
- **狀態時間占比**：可選全廠或單台。全廠分母固定為十台乘上區間時間；未知保留在分母內。此圖是互斥狀態分布，不是加工稼動率；Dummy 驗證可以包含搬送等待。
- **各機台完成與報廢**：正式晶圓依結案時間計數，每台每片只計一次。正常完成需回原槽，異常補做／報廢還需有效 PE 確認；兩者取最後必要證據時間。Leader 放行不增加片數。Dummy 完成／報廢獨立列出。完成不代表製程能力合格率，沒有 Cp／Cpk。

資料不足時顯示「已知片數 · 資料不完整」，0 僅代表沒有已知結案。狀態與結案資料涵蓋率各自計算。舊版本缺少分類證據的區間為未知；可靠回槽與簽核事件可回填舊結案，但不把補送抵達時間當結案時間。

## 資料與維運

新來源使用既有 SECS/GEM → Sparkplug B → Kafka 鏈路。契約及新舊樣本見 `contracts/STATISTICS.md`、`statistics-example.json`、`statistics-legacy-example.json`。查詢端點 `GET /api/equipment/statistics` 僅讀取；登入的三角色皆可用，非法機台或區間回 400，未登入回 401。

TimescaleDB `statistics_second` 每秒去重，`statistics_minute` 同交易彙總，保留 30 天。衝突的秒保持未知；相鄰同狀態／旗標可合併，混合區段列出各分類時間。概覽解析度為 60／300／1800 秒，每台至多 2,017 個桶（含邊界），不傳全量秒資料。

PostgreSQL `statistics_closures` 以設備／晶圓唯一鍵保存結案；`statistics_receipts` 與 `statistics_eras` 校驗來源連續水位。來源 checkpoint 保存 era、序號與結案時間，重啟不清空。缺事件時利用原 checkpoint 的完整證據重建；舊資料回填每次最多 40 片且可重跑。超過 30 天的完成批次只清詳細 payload，保留去重墓碑；活動 FOUP 與處置沿用既有歷史保留保護。

## 升級與回退

先用 `scripts/secs-backup.py` 對十台及全部持久卷作一致性備份。結案與狀態資料表為新增，未改原 recipe、簽核或批次結構；checkpoint 新增欄位，原批次／保養鎖應逐台核對。模擬器重啟後維持時鐘暫停，需按既有權限與保養／處置規則人工恢復。

若須回退，停止整組服務，使用同一份備份的 Compose、資料庫及所有狀態卷完整還原（流程見 SECS_GEM_DEPLOYMENT.md），不能混用新結案資料與舊 checkpoint。回退也不自動啟動加工。
